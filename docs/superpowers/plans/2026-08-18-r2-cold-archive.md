# R2 Cold Archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move bulky HubSpot snapshots and generic attachment metadata to private Cloudflare R2 without changing QuotePulse's visible CRM behaviour.

**Architecture:** Supabase remains the owner-scoped hot relational store. A server-only R2 client writes verified, owner-scoped archive objects; small relational pointers retain retrieval and migration state. Existing rows are copied and checksum-verified before redundant Postgres data is removed.

**Tech Stack:** Vite/React/TypeScript, Supabase Postgres/Auth/Edge Functions, Cloudflare R2 S3 API, Vitest.

## Global Constraints

- Keep R2 credentials only in Supabase Edge Function secrets.
- Explicitly scope every service-role read/write by `owner_id`.
- Retain all quote attachments and quote OCR behaviour in Supabase.
- Never delete a Postgres payload before verifying its R2 copy.
- Preserve the existing frontend routes and user-visible workflow.
- Do not overwrite unrelated working-tree edits.
